03 / Formação

Disciplinas.

A unidade de formação do projeto e os temas de programação explorados no site.

01 / UCUtilizar serviços Git e GitHub

A UC00617, orientada pela formadora Sara Monteiro, abrange controlo de versões com Git, colaboração com branches e pull requests, revisão de código e publicação com GitHub Pages.

02 / WebDesenvolvimento web

O site usa HTML para estruturar o conteúdo, CSS para criar uma interface responsiva e JavaScript para as demonstrações e o modo de apresentação.

03 / AlgAlgoritmos e sistemas de numeração

O descodificador lê uma sequência de zeros e uns e apresenta o mesmo valor em base decimal e hexadecimal.

04 / Colaboração

Workflow.

As etapas previstas no enunciado para trabalhar em equipa no repositório do projeto.

01 / Configurar

Repositório

O responsável cria o repositório público do grupo e configura a proteção da branch principal com uma aprovação obrigatória.

02 / Desenvolver

Clone e commits

Cada colega clona o repositório, trabalha na sua branch e regista as alterações em commits claros e específicos.

03 / Rever

Pull requests

Os colegas abrem pull requests, deixam comentários técnicos e integram as alterações após a aprovação.

04 / Publicar

GitHub Pages

O responsável ativa o GitHub Pages e a equipa confirma que o site funciona no endereço público.
